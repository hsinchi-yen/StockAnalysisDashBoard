流動比率 / 速動比率（季度）

流動比率 = 流動資產 / 流動負債（安全線 > 2）；速動比率 = (流動資產 - 存貨) / 流動負債（安全線 > 1）。

資料表

每股淨值（BVPS）趨勢

BVPS = 股東權益 / 流通股數。持續成長代表公司帳面價值不斷提升。

歷年負債比（季度）

負債比 = 負債總計 ÷ 資產總計 × 100%。40% 以下財務穩健；60% 以上需留意償債風險。

資料表

自由現金流量（歷年）

自由現金流量 = 營業活動現金流量 − 資本支出（取年度 Q4 全年值）。標示 * 者為當年度尚未結算、以最新一季累計值呈現的部分年度，不納入平均計算。

自由現金流量（季累積）

每一季為該會計年度的累計值（Q1、上半年、前三季、全年），會在年初歸零重新累計。資料點較歷年圖更密集，依上方年份區間顯示。

DSO＝應收天數、DIO＝存貨天數、DPO＝應付天數、CCC＝現金轉換循環。天數越短代表效率越高。

多維估值比較

Graham Number = √(22.5 × 平均 EPS × 最新 BVPS)；PEG = 本益比 / EPS 3 年 CAGR。

前瞻性滾動估值 (Forward Rolling EPS)

以近 3 個月月營收 YoY × 最新季度利潤率因子調整去年全年 EPS，再乘以歷史 P/E 百分位，估算未來一年股價區間。

DCF 現值估價（Gordon Growth Model）

公允價值 ＝ EPS × 配息率 × (1+g) ÷ (r−g)；以近 N 年平均 EPS 與配息率計算。
